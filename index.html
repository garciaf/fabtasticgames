Getting the party started

One person starts the game on the TV, everyone else joins with the phone already in their pocket. The game itself isn't played on this website.

  1. 1

    Start the game on the big screen

    Launch it on your computer and put it on the TV. A room code appears.

  2. 2

    Everyone grabs a phone

    Open the web address shown on the TV in any phone browser. Nothing to install.

  3. 3

    Type the code, start the fun

    Enter the room code and your name, and you're at the table.
